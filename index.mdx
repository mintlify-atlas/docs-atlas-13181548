The Cinema Backend API is a RESTful service built with Express.js that provides complete management of cinema operations. It exposes five core resources — movies, screening rooms, show functions, tickets, and reservations — each with full CRUD support and a consistent JSON response format.

## How it works

The API organises cinema operations around five linked resources:

<Steps>
  <Step title="Create movies and rooms">
    Add movies (`/peliculas`) with a title, genre, and duration. Add screening rooms (`/salas`) with a name and seating capacity.
  </Step>
  <Step title="Schedule show functions">
    Create a show function (`/funciones`) that links a movie to a room at a specific date and time.
  </Step>
  <Step title="Issue tickets">
    Generate tickets (`/tickets`) for a function, assigning a seat number and price to each one.
  </Step>
  <Step title="Accept reservations">
    Create a reservation (`/reservaciones`) that associates a customer with a ticket and a booking date.
  </Step>
</Steps>

<Note>
  The server uses an in-memory store. All data resets when the process restarts. There is no authentication — every endpoint is open.
</Note>
