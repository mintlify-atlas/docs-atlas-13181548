---

The **List Reservations** endpoint returns the complete collection of reservations currently held in the system. When at least one reservation exists the response `data` field contains the full array; when the store is empty `data` is `null` and the message communicates that no reservations have been registered yet.

## Endpoint

```http
GET /reservaciones
```

## Request

No path parameters, query parameters, or request body are required for this endpoint.

### Example Request

```bash
curl http://localhost:3000/reservaciones
```

## Responses

### 200 — Success (reservations found)

```json
{
  "data": [
    {
      "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "cliente": "María González",
      "ticketId": "f9e8d7c6-b5a4-3210-fedc-ba9876543210",
      "fecha": "2025-07-20"
    },
    {
      "id": "b2c3d4e5-f6a7-8901-bcde-f12345678901",
      "cliente": "Carlos Ramírez",
      "ticketId": "e8d7c6b5-a493-2101-edcb-a98765432109",
      "fecha": "2025-07-22"
    }
  ],
  "message": "Reservaciones listadas exitosamente"
}
```

### 200 — Success (store is empty)

When no reservations have been created yet the server still responds with HTTP **200** but sets `data` to `null`.

```json
{
  "data": null,
  "message": "No hay reservaciones registradas"
}
```

## Response Fields

| Field       | Type            | Description                                      |
|-------------|-----------------|--------------------------------------------------|
| `data`      | `array \| null` | Array of reservation objects, or `null` if empty |
| `message`   | `string`        | Human-readable status message                    |

### Reservation Object

| Field      | Type     | Description                              |
|------------|----------|------------------------------------------|
| `id`       | `string` | UUID generated by the server             |
| `cliente`  | `string` | Customer name                            |
| `ticketId` | `string` | UUID of the associated ticket            |
| `fecha`    | `string` | Reservation date (e.g. `"2025-07-20"`)  |
