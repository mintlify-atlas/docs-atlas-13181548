---
title: "Filter Reservations by Date Range – Cinema Backend"
sidebarTitle: "By Date Range"
description: "Query reservations whose fecha falls between two dates (inclusive). Pass inicio and fin as ISO date strings to get a filtered array of records."
---

The **By Date Range** endpoint filters reservations by their `fecha` field, returning every reservation whose date falls on or between the `inicio` and `fin` values you supply. The comparison is performed using JavaScript `Date` objects — `new Date(r.fecha) >= new Date(inicio) && new Date(r.fecha) <= new Date(fin)` — making it inclusive of both boundary dates. Both query parameters are required; omitting either will produce an empty or unexpected result set.

## Endpoint

```http
GET /reservaciones/busqueda/fecha
```

### Query Parameters

<ParamField query="inicio" type="string" required>
  The start of the date range. Must be a valid ISO date string (e.g. `"2025-07-01"`). Reservations on this date are **included** in the results.
</ParamField>

<ParamField query="fin" type="string" required>
  The end of the date range. Must be a valid ISO date string (e.g. `"2025-07-31"`). Reservations on this date are **included** in the results.
</ParamField>

## Request

### Example Request

```bash
curl "http://localhost:3000/reservaciones/busqueda/fecha?inicio=2025-07-01&fin=2025-07-31"
```

## Responses

### 200 — Success

The endpoint always returns HTTP **200**. When no reservations fall within the range, `data` is an empty array.

```json
{
  "data": [
    {
      "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
      "cliente": "María González",
      "ticketId": "f9e8d7c6-b5a4-3210-fedc-ba9876543210",
      "fecha": "2025-07-20"
    },
    {
      "id": "b2c3d4e5-f6a7-8901-bcde-f12345678901",
      "cliente": "Carlos Ramírez",
      "ticketId": "e8d7c6b5-a493-2101-edcb-a98765432109",
      "fecha": "2025-07-22"
    }
  ],
  "message": "Reservaciones filtradas por fecha exitosamente"
}
```

### 200 — No Matches

```json
{
  "data": [],
  "message": "Reservaciones filtradas por fecha exitosamente"
}
```

## Response Fields

| Field     | Type     | Description                                         |
|-----------|----------|-----------------------------------------------------|
| `data`    | `array`  | Reservations whose `fecha` falls within the range   |
| `message` | `string` | Human-readable status message                       |

### Reservation Object

| Field      | Type     | Description                              |
|------------|----------|------------------------------------------|
| `id`       | `string` | UUID of the reservation                  |
| `cliente`  | `string` | Customer name                            |
| `ticketId` | `string` | UUID of the associated ticket            |
| `fecha`    | `string` | Reservation date (e.g. `"2025-07-20"`)  |
