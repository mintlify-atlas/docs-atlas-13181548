title: "List All Cinema Show Functions — Cinema Backend API"
sidebarTitle: "List Functions"

---

The **List Functions** endpoint returns every scheduled show function currently stored in the Cinema Backend. A function (función) represents a single scheduled screening that links a movie to a room at a specific date and time. This endpoint is read-only, requires no request body, and always returns HTTP `200` — even when no functions have been created yet.

<Note>
  Functions link movies to rooms via `peliculaId` and `salaId`. The API does **not** validate that these UUIDs correspond to existing records — it only checks that the fields are present when creating a function. Always ensure the referenced movie and room exist before treating a function as fully valid.
</Note>

## Endpoint

```http
GET /funciones
```

## Response Body

| Field     | Type            | Description                                                  |
| --------- | --------------- | ------------------------------------------------------------ |
| `data`    | `array \| null` | Array of function objects, or `null` if none are registered. |
| `message` | `string`        | Human-readable status message.                               |

### Function Object

| Field        | Type     | Description                                        |
| ------------ | -------- | -------------------------------------------------- |
| `id`         | `string` | UUID automatically assigned by the server.         |
| `peliculaId` | `string` | UUID of the movie linked to this function.         |
| `salaId`     | `string` | UUID of the room where the screening takes place.  |
| `horario`    | `string` | ISO 8601 datetime string for the scheduled showing.|

## Example Request

```bash
curl -X GET http://localhost:3000/funciones
```

## Response Codes

| Status | Meaning                                                           |
| ------ | ----------------------------------------------------------------- |
| `200`  | Request succeeded. `data` contains the array or `null` if empty. |
