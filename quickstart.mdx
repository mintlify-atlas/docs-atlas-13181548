This guide walks you through everything you need to go from zero to a running Cinema Backend API server and your first successful API call. The whole process takes less than five minutes if you already have Node.js installed.

<Steps>

<Step title="Prerequisites">

Make sure the following tools are available on your machine before you begin:

- **Node.js 18 or later** — check with `node --version`
- **npm** (bundled with Node.js) or **yarn**

No database, Docker image, or external service is required. All data is stored in memory.

</Step>

<Step title="Clone the Repository">

Clone the project from GitHub and change into the new directory:

```bash
git clone https://github.com/Juanfc1103/backend2026c-1.1.git && cd backend2026c-1.1
```

</Step>

<Step title="Install Dependencies">

Install all Node.js dependencies declared in `package.json`:

<CodeGroup>

```bash npm
npm install
```

```bash yarn
yarn install
```

</CodeGroup>

This pulls in Express 4, Morgan, uuid, EJS, cookie-parser, and the other packages listed in `package.json`.

</Step>

<Step title="Start the Server">

Choose the mode that fits your workflow:

<CodeGroup>

```bash Production
npm start
```

```bash Development (hot-reload)
npm run dev
```

</CodeGroup>

<Note>
`npm run dev` uses **nodemon** to watch for file changes and automatically restart the server — useful while you are actively developing or experimenting. `npm start` runs the server once with plain `node`.
</Note>

When the server is ready you will see Morgan's request logger activate. No explicit "listening" message is printed to stdout by default, but the process will stay alive and accept connections on **http://localhost:3000**.

```
> node ./bin/www
```

The server binds to `PORT` from the environment, defaulting to **3000**. To use a different port:

```bash
PORT=8080 npm start
```

</Step>

<Step title="Make Your First Request">

With the server running, open a new terminal and create your first movie record:

```bash
curl -X POST http://localhost:3000/peliculas/create \
  -H "Content-Type: application/json" \
  -d '{"titulo": "Inception", "genero": "Sci-Fi", "duracion": 148}'
```

A successful response looks like this (the `id` value will differ each run — it is a UUID v4 generated server-side):

```json
{
  "data": {
    "titulo": "Inception",
    "genero": "Sci-Fi",
    "duracion": 148,
    "id": "a3f1c2d4-58e0-4b7a-9f6d-1234567890ab"
  },
  "message": "Película agregada exitosamente"
}
```

Every response from the Cinema Backend API follows this `{ data, message }` envelope regardless of the resource or operation.

</Step>

</Steps>
